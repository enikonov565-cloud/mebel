# Антураж интерьер

Одностраничный сайт мастерской по изготовлению мебели и предметов интерьера из массива дерева на заказ.

Разделы: главная, о компании, услуги, материалы, как мы работаем, преимущества, работы, отзывы, вопросы и ответы, контакты.

Сайт полностью самодостаточен: один файл `index.html` со встроенными шрифтами (GOST, Inter), без внешних зависимостей.

## Публикация (GitHub Pages)

1. В репозитории: **Settings → Pages**.
2. **Source**: Deploy from a branch.
3. **Branch**: `main`, папка `/ (root)`.
4. **Save**.

Через 1–2 минуты сайт будет доступен по адресу:
`https://enikonov565-cloud.github.io/mebel/`
